## AIプロンプト集・関数例

[AIプロンプト集・関数例を開く](AIプロンプト集.md)

講座で使う関数・QUERY の例と、AIへの依頼文（プロンプト）をまとめています。コードブロック右上のコピーボタンで、そのまま貼り付けられます。パスワード、ライトキー、合言葉（token）、受信用URL は、AIに貼る前に仮の値へ置き換えてください。

## 第1回のサンプルプログラム（M5StickC → MiniBient）

[samples/m5stickc_minibient_sender.py](samples/m5stickc_minibient_sender.py)

第1回で使った、M5StickC と ENV III で温度・湿度・気圧を測り、MiniBient に HTTPS で送るプログラム（UIFlow2 系の MicroPython）です。

- 使うときは、先頭の `CHANNEL_ID` と `WRITE_KEY` を自分のチャネルの値に書きかえます。送信間隔は `SEND_INTERVAL_SEC`（30秒）です。
- 書きかえた後のファイル（実際のライトキー入り）は、AIに貼ったり、GitHub などに公開したりしないでください。
- 第2回の GAS 送信の実習で、第1回のプログラムが手元にない人は、これをコピーして使います（AIに貼るときは `WRITE_KEY` を仮の値のままにします）。
- 講座の後に MiniBient への測定に戻すときも、このプログラムを使えます。

## GAS 受信コード（ひな形）

[gas/iot_receiver.gs](gas/iot_receiver.gs)

M5StickC（第3回は Node-RED）から送られた温度・湿度・気圧を、自分のスプレッドシートの「受信データ」シートに1行ずつ記録する Google Apps Script です。ファイルを開き、右上の「Copy raw file」ボタンで全体をコピーできます。

1. 受信用のスプレッドシートを新しく作り、［拡張機能］→［Apps Script］を開きます。
2. 最初からあるコードを全部消して、このコードを貼り付けて保存します。
3. 関数「setup」を選んで［実行］し、承認画面で内容を確かめてから承認します。実行ログに表示される合言葉（token）を控えます。
4. ［デプロイ］→［新しいデプロイ］→ 種類「ウェブアプリ」。次のユーザーとして実行「自分」、アクセスできるユーザー「全員」でデプロイし、ウェブアプリの URL（…/exec）を控えます。

- 合言葉と受信用 URL は、AIに貼ったり、人に見せたりしないでください。コード自体には合言葉は書かれていないので、コードはそのままAIに貼ってかまいません。
- コードを直したときは、［デプロイ］→［デプロイを管理］→ 編集 → バージョン「新バージョン」でデプロイし直します（URL は変わりません）。
- 送るデータの形式は、[AIプロンプト集の 4-1](AIプロンプト集.md) を見てください。

## 現場Aの測定データ

[現場Aの測定データを開く（Googleスプレッドシート）](https://docs.google.com/spreadsheets/d/1TDOBpsr7aPwyIMrRbO-UeuNlvRa1ZJ6o5NACQNvN3do)

このファイルは、IMPORTRANGEの練習に使う架空データです。講座で使用するGoogleアカウントで開いてください。アクセスできない場合は講師に伝えてください。

シート名は「現場A」、範囲は A1:G15 です（1行目が見出し、2〜15行目が11月1日〜14日の14日分）。

| 列 | A | B | C | D | E | F | G |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 項目 | 日付 | 現場 | 平均温度_℃ | 最高温度_℃ | 最低温度_℃ | 記録者 | 備考 |

## 自分のスプレッドシートに取り込む

1. 自分の「測定データ分析」ファイルに「参照」シートを追加します。
2. 「参照」シートのA1に、次の式を入力します。
3. 式の「現場AのスプレッドシートURL」を、上のリンクを開いたときのURLに置き換えます。
4. `#REF!` が表示されたら、そのセルで「アクセスを許可」をクリックします。

```
=IMPORTRANGE("現場AのスプレッドシートURL", "現場A!A1:G15")
```

見出しと14日分のデータが表示されたら完了です。参照元ファイルを自分のGoogle Driveにコピーする必要はありません。

QUERYの練習は講座スライドP42を確認してください（C列＝平均温度_℃ を Col3 で指定します）。

## P43　2つの現場の記録を1つの表にまとめる

配布された集計用テンプレートを開き、［ファイル］→［コピーを作成］で自分用のコピーを作ります。「リンク」シートには次のURLが入力済みです。

| セル | 記録元 |
| --- | --- |
| B2 | [現場A（事務所）](https://docs.google.com/spreadsheets/d/1TDOBpsr7aPwyIMrRbO-UeuNlvRa1ZJ6o5NACQNvN3do) |
| B3 | [現場B（倉庫）](https://docs.google.com/spreadsheets/d/1VIy7f0svUV3aGCxo6g7B4ScA85jb6wXv5yrfR4rv55w) |

### 1. 各ファイルの記録を取り込む

各取込シートのA1に、対応する式を入力します。接続を求める表示が出たら、そのセルで［アクセスを許可］をクリックします。

**現場A取込**

```
=IMPORTRANGE(リンク!B2, "現場A!A1:G15")
```

**現場B取込**

```
=IMPORTRANGE(リンク!B3, "現場B!A1:G15")
```

### 2. 28件の記録をまとめる

「集計」シートのA1に次の式を入力します。現場Bは2行目から取り込み、現場Aの見出しだけを残します（見出しを重複させないため）。

```
={'現場A取込'!A1:G15;'現場B取込'!A2:G15}
```

1行目が見出し、2〜15行目が現場A、16〜29行目が現場Bになれば完了です。
